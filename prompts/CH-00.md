### 3. The run logger — the real work of this chunk

`src/runlog.py`. Every agent invocation in this project goes through it. **Rule 10: no exceptions, from the first run.** It cannot be retrofitted and it is a submission gate item.

**Per run, write one JSONL file to `docs/trajectories/<run_id>.jsonl`.** One JSON object per line:

| Record type | Fields |
|---|---|
| `run_start` | `run_id`, `arm`, `item_id`, `model`, `timestamp_utc`, `agent_instructions` (the full system/task prompt given) |
| `action` | `step`, `type` (`tool_call` / `message`), `name`, `input` |
| `tool_response` | `step`, `name`, `output`, `error` (null when clean) |
| `feedback` | `step`, `what_changed_the_next_step` — the observation that shaped what came next |
| `retry` | `step`, `reason`, `attempt` |
| `human_checkpoint` | `step`, `reason`, `resolution` |
| `run_end` | `verdict`, `input_tokens`, `output_tokens`, `wall_clock_s`, `imputed_usd`, `model`, `price_basis` |

**Cost accounting.** `imputed_usd` is computed from a `PRICES` dict of published per-million list prices, keyed by model id, with the price basis and its source URL recorded in the run. The build subscription is flat-cost — **impute and say so. Never emit `$0`.**

**Also emit `docs/evidence/runs/cost_ledger.csv`** — one row per run: `run_id, arm, item_id, model, input_tokens, output_tokens, wall_clock_s, imputed_usd`. Append-only. This is the source for the *cost per task* and *human time per task* rows the rubric asks for, which only two repositories on all of GitHub currently carry.

**HARD SPEND CEILING — build it into the logger now, not later.** The logger maintains a cumulative USD total across all runs (read from `docs/evidence/runs/cost_ledger.csv` at start-up) and **raises before starting any run that would push the total past `SPEND_CEILING_USD = 18.00`**, printing the ledger and the remaining headroom. The operator's hard ceiling is USD 20; the code stops at 18 so a surprise cannot reach it. A budget discovered after it is spent is not a budget.

**Interface** — keep it this simple, because every later chunk depends on it:
```python
with RunLogger(arm="B0", item_id="42-433.2", model="...") as log:
    log.action("tool_call", name="cfr_resolve", input={...})
    log.tool_response(name="cfr_resolve", output={...})
    log.feedback("anchor not found at exact level; retrying whitespace-collapsed")
    log.retry(reason="...", attempt=2)
    log.human_checkpoint(reason="...", resolution="...")
    log.finish(verdict="WILL_FAIL", input_tokens=..., output_tokens=...)
```
Wall-clock and `imputed_usd` are computed by the logger, not passed in.

**Also install a pre-commit hook.** `.githooks/pre-commit` + `git config core.hooksPath .githooks`. It rejects any commit where a staged file exceeds 25 MB or the tracked count exceeds 300, and re-runs the PII sweep. The CH-00 one-off assertion protects the tree as it stands today; **the hook protects the tree every later chunk creates**, which is where the 50 MB cap actually gets broken.
