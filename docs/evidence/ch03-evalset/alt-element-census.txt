==============================================================================
WHAT WAS DONE ABOUT IT
==============================================================================

  NOTHING was added to the stripper. CONTEXT.md section 8 names four elements
  and adding a fifth is a Class A spec change, which belongs to the architect
  and not to the session that found it (QUESTIONS.md Q17).

  The affected items were EXCLUDED on the named ladder rung
  `leakage-test-failed-after-strip`. That makes the eval set SMALLER, which is
  the conservative direction; extending the stripper would have made it larger
  after the number was in view, which is the direction this project refuses.

  The defence that caught it was pre-registered: plan.md's leakage test checks
  LITERALS as well as element names, so it fires on content the element list
  misses. That is the reason the test has three rules and not one.
