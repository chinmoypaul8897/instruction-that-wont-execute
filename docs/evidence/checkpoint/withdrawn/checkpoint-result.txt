  20-item sonnet gap set against a 76-item haiku gap would be two
  different item sets with the difference called a model effect.

  QUESTIONS.md Q1 anticipated the OPPOSITE failure - that a cheap model
  would fail to use the text and we would kill a sound project on weak
  inference. What was measured is the reverse: the CHEAPER model gains
  from the text and the STRONGER one loses. The RED branch was not taken
  and this does not rescue or threaten the AMBER branch either way, which
  is decided on the full-corpus haiku arms alone.

  THREE REASONS NOT TO OVER-READ THIS, stated before anyone else says them:
   1. n = 20, ONE rep. The haiku arms are n = 76 and three reps.
   2. A CONFOUND, not merely a limitation: sonnet-5 REJECTS `temperature`
      (HTTP 400, measured), so this subset ran at the model default while
      every haiku arm ran at 0. A sampling difference is a live
      alternative explanation for a reversal of this size and it has not
      been ruled out.
   3. One rep gives no variance estimate at all, so the -15.0 pp has no
      interval around it.

  It is reported because it was pre-registered and run, not because it is
  a result this project wanted. CH-08 can settle it with reps at a
  matched sampling setting; tonight it is a flag, not a finding.
