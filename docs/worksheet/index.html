Codification worksheet

Federal Register amendatory instructions, executed against the point-in-time CFR text - one row per instruction, with the anchor, the normalisation level it resolved at, the designation state, and the siblings when it did not resolve.

NOT A FILING. NOT LEGAL ADVICE. NOT REVIEWED BY A QUALIFIED REVIEWER.
This worksheet is an input to a licensed regulations drafter's judgement. It does not file anything, does not amend anything, and takes no consequential action. No output on this page has been reviewed by a qualified regulations drafter or by any other qualified reviewer - not one row. The verdicts below are the measured output of an evaluation arm whose pre-registered success criterion was NOT MET on all four clauses, and which agrees with gold on 59 of 82 items. Every unresolved case routes to the human-checkpoint queue at the foot of this page rather than being decided here.
Self-contained: no script, no network, no external font, no build step. Opens from a clean clone by double-clicking, with the network off.

Which items are shown, and why

A worksheet showing all 82 items would be unreadable, and one showing a hand-picked few would be unfalsifiable. The rule below is deterministic, ties break on sorted item_id, and it is applied by docs/evidence/ch12/build_worksheet.py - the same script that writes this page. It selected 10 items. The complete per-item output for all 82 is in the artifacts file named above; nothing is hidden by this page, only unrendered.

W1the composition exemplar named in docs/evidence/ch06-a1/EXEMPLAR-composition.md - the item where the model overrode cfr_resolve and published the tool's limitation
W2for every distinct failure class A1 emitted, the first item carrying it by sorted item_id
W3for every distinct human-checkpoint reason class (C1 / C2 / C3), the first item carrying it by sorted item_id
W4every item where an anchor resolved at a normalisation level other than exact - hard rule 7 says the level achieved is reported, never applied silently
W5the first item by sorted item_id whose emitted verdict disagreed with gold - failures are never filtered out
